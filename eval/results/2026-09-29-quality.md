# Quality changes, 2026-09-28 and 2026-09-29

Numbers are copied from commit messages and the earlier result files in this folder. Nothing here was re-measured for this note.

## Measured steps

| date | change | measured effect |
|---|---|---|
| 2026-09-28 | Paper index on bge-base, dense paper weight 2.0 | citation-context benchmark, test split (334 queries): hit@3 0.359 -> 0.377, hit@10 0.422 -> 0.458. Golden 15/17 -> 17/17. Details in 2026-09-28-bge-base.md |
| 2026-09-28 | One result per paper across sources (17,614 ACL/PMLR/OpenAlex copies of arXiv papers) | security hand set hit@3 0.571 -> 0.607; web3 hand set and golden unchanged |
| 2026-09-29 | Boilerplate chunks never represent a paper | security hand set hit@3 0.571 -> 0.643 (commit message figure) |
| 2026-09-29 | Citation-graph channel in chunk search (HIER_W_GRAPH=0.8) | security hand set hit@3 0.643 -> 0.714; rank harness (canonical paper in top 3) 5 -> 7 of 19; golden 17/17; p50 latency +95 ms |

Context for the first row: the same test split scored hit@3 0.195 on production search before hierarchical retrieval (2026-09-26-baseline.md) and 0.359 after it (2026-09-27-search-v2.md). The rank harness was 4/19 in 2026-09-28-bge-base.md; the 5/19 in the 2026-09-29 commit is the figure right before the graph channel.

The security hand set has 28 queries (baseline hit@3 0.571, recorded 2026-09-28). It is small: one query is 3.6 points.

## Changes with no retrieval metric

- LaTeX `\input` resolved by archive path. About 24% of papers had lost their body because `\input{sections/x}` was looked up by basename. Example from the commit: SWE-bench 2 -> 154 chunks. Papers that lost their body are being reprocessed, most cited first.
- Scope signal (`in_scope`) added to search, papers and facets, and acronyms made case-sensitive (MEV is not MeV). Golden 17/17. Distance alone gives `null`, never `false`.
- 2665 papers admitted only through case-blind acronym matches (MeV physics, Stark, wormholes, Swift GRBs) purged from the index; 239 lose a layer.
- Twins extended by arXiv id in the source url, identical abstract openings and fuzzy titles (+878 links).
- Corpus additions: ERCs from ethereum/ERCs under their `eip:N` ids (198 stubs refreshed, about 251 ERCs new); Solana, Anchor v2, SVM spec and DeFi protocol docs; whitepapers for Uniswap v4, Curve CryptoSwap, Aave v2/v3, Chainlink v1, Pyth.
- Second chunk embedder (bge-small on the Oracle host beside bge-base, with failover); memory of that service 2.5 GB -> 0.7 GB.
- MCP: a non-UTF-8 request body now gets a JSON-RPC parse error with a hint instead of -32603.
