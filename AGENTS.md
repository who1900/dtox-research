# DTOX Research — вход из Git-репозитория

Это исходный код DTOX Research. Начните с [README](README.md) и [руководства разработчика](docs/technical-reference.md). Датированные планы и отчёты сохраняются во внутренней истории рабочего пространства и сами по себе не выбирают следующее задание.

В локальном пространстве аудита управляющие документы находятся на два уровня выше: `../../AGENTS.md`, `../../PROJECT_CONTEXT.md`, `../../docs/WORKFLOW.md`. Если они присутствуют, основной набор правил находится там; этот файл только направляет к нему. Отдельный GitHub checkout не требует наличия этих внешних файлов.

Команды Python выполняются из корня репозитория. Выбирайте проверки по изменённому поведению; MCP tests запускаются через discovery (`python -B -m unittest discover -s mcp/tests`), поскольку установленный пакет `mcp` имеет то же имя. Node-команды выполняются в `attestor/` или `x402-gateway/`. Linux-only operations проверяются в Linux; Windows syntax/offline PASS не устанавливает live deployment.
