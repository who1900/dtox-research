# dtox research pitch deck

This package contains a 13-slide core startup pitch and two appendix slides. It is written for both investors and Web3 developers, with Web3 research as the primary product and agent clients as the delivery layer.

- `dtox-research-pitch.pptx` is the editable master. Text and the competitor comparison table are native PowerPoint objects. The source equation includes readable notation and the original editable LaTeX string.
- `dtox-research-pitch.pdf` is a 15-page visual export from the rendered slides. It is not a full-text editable PDF. Selected visible URLs are clickable.
- `index.html` is a standalone, dependency-free deck with keyboard navigation, a speaker-notes toggle, and slide-only printing.
- `cover.png` is the rendered cover slide.
- `evidence.md` records the supporting sources and claim boundaries.
- `QA-questions.md` contains concise answers to likely investor and developer questions.

The deck uses Arial and Consolas. Inter and Roboto Mono were not installed in the available runtime, so these verified local families provide the closest practical system-font fallback. No external font or image assets are required.

Snapshot figures are dated October 5, 2026 at 09:30 UTC. Founder experience and app listings are attributed to the founder-provided CV. No customer traction, revenue, pricing validation, market-size estimate, or fundraising amount is claimed.
