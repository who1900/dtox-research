Project description

Execution agents need more than a list of papers before their builders choose a transaction path or account architecture. dtox is a Web3-first research service that lets agents find and read protocol specifications, technical papers and whitepapers through MCP. It returns source-linked material with acquisition and extraction provenance, including equations, algorithms, code and stated limitations when available. A bounded research bundle assembles a reading packet under a character budget. It is evidence for a human or agent to inspect, not an automatic security review or novelty verdict.

One research path pairs the MEV auction model in Quantifying Blockchain Extractable Value: How dark is the forest? with ERC-4337's discussion of EntryPoint risk concentration and account-abstraction safety. The paper source is original LaTeX; the ERC-4337 passage is specification text, not dtox-generated advice. Their juxtaposition supports cross-ecosystem research, not equivalence between chain assumptions.

The public read beta is free and needs no key or signup. The public MCP inventory exposes 13 tools: 12 read/preview tools and one signed-write tool, record_signed_verdict. The signed-write tool was not invoked in this release check; no legacy anonymous-write tool appeared in the inventory. Separately, a wallet can sign a reading for Solana Attestation Service anchoring. A signature makes attribution checkable; it does not prove correctness, independent reasoning or scientific consensus.

This is a known recall miss for this idea/claim, not evidence of a newly introduced regression. Historical examples are not a guarantee of future retrieval.
