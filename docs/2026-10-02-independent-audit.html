01 / FINDINGS

Шесть важных рисков

Приоритет отражает последствия. Воспроизведенный дефект не равен произошедшему production-инциденту.

P1 / F01

Pipeline не откатывает транзакцию

После exception connection остается без rollback. Изолированный SQLite fixture удержал writer lock; живой heartbeat может скрывать отсутствие прогресса.

Текущий production lock не доказан: в недавнем tail его нет.

P1 / F02

Точный код может измениться

Валидный verbatim подтвердил удаление % 2; из int rem = value % 2;. Это потеря семантики, а не форматирования.

Частота повреждений в корпусе неизвестна.

P1 / F03

Почти нет запаса ресурсов

Qdrant около 98,8% лимита. Contabo уже ниже disk threshold. Свободное место Oracle не решает дефицит другого хоста.

OOM не наблюдался; причина latency не установлена. Blind raise 10 GiB на хосте 12 GB недопустим.

P2 / F08-F11, F16-F18

Обновление и recovery не доказаны

HAL не переоткрывает done cursors; state/coarse/FTS могут расходиться, replay не идемпотентен. Подготовка verdict создает локальные claim nodes вопреки writes nothing.

Backup helper может выбрать не свежую копию и вернуть ok без обязательной таблицы. as_of не фиксирует индекс; turnkey self-host не подтвержден.

P2 / F13-F15 / PAID GATE

Оплата не равна безопасной записи

В рассмотренном flow handler идет до settlement: chain write может завершиться до payment failure. Partial/all-invalid results требуют явной billing policy и idempotency E2E.

Paid bundle сейчас вызывает search. Публичные обещания quorum и числа tools устарели. Списаний или mainnet exploit сегодня не доказано.

03 / UNVERIFIED

Границы доказательств

Не проверено

  • Overnight SLO, репрезентативные tool p95/p99 и причинная декомпозиция latency.
  • Fresh restore, coarse_base recovery, RTO/RPO, corpus-wide parsing и полнота index reconciliation.
  • Builder-tech: качество покрытия; license: полнота лицензий и прав использования корпуса и code fragments.
  • Paid settlement и chain E2E, mainnet readiness, adoption и unit economics.

Чего нельзя обещать

  • 13/13 production tools E2E: signed writes в production не вызывались.
  • Автоматическое научное подтверждение: public models=[] остаются pending; wallets не доказывают независимое reasoning.
  • Полную независимость вердикта от wording: citation traversal зависит от seeds, а links фиксируют ручное решение.
  • Четыре live paid networks, доказанный OOM/SQLite lock или полный security audit. Ограниченный tracked-text scan ничего не нашел, но history не покрыт.

Production проверялся read-only, без платежей, транзакций, signed writes и deployed fixes. Unknown не равно fail, но не заменяет доказательство release gate.

04 / PLAN

Порядок исправлений

Это план дальнейших работ, не выполненные изменения. Первые исправления не требуют дополнительного LLM или model spend.

  1. Rollback и watchdog реального прогресса. Исключение после INSERT не держит writer lock; heartbeat не маскирует бесконечные ошибки.
  2. Source integrity и taxonomy. Сохранить literal %, исходный порядок prose/code и наследование Security; адресно оценить поврежденные источники.
  3. Registry/report/coverage/trends contracts. Согласовать current/similar/pending, canonical IDs, truncation и protocol errors; проверить wording regressions.
  4. RAM и disk policy. Раздельный бюджет хостов, безопасная retention и запас для snapshot/ingestion, без слепого увеличения лимитов.
  5. Ingestion и reconciliation. Уважать 429, fair priorities, HAL refresh, source-owned cursors, idempotent FTS; добавить first-completion journal.
  6. Regression release и честные public docs. Targeted tests, backup schema/freshness и разрешенный restore; затем опубликованный commit/CI и self-host smoke.
  7. Unpaid vs settled paid gate. Разрешенные testnet E2E оплаты, settlement, chain write и failure/retry; billing/value policy, затем отдельное решение о mainnet.
