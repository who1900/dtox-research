# dtox research - visual pitch package

This folder contains the refreshed English, 13-slide pitch deck and its review materials.

- [PowerPoint deck](dtox-research-visual.pptx)

The deck presents dtox as a Web3-focused research tool that brings papers, protocol specifications, formulas where recoverable, and source limitations together with citations. The public MCP offers 13 tools; read access is free. The public landing describes BGE-base dense embeddings for papers and BGE-small embeddings for chunks. Corpus counters are inventory measures, not usage or traction. Full text varies by source. Do not present paid commercial access as launched: paid heavy-usage access is a plan, not a validated revenue stream. The on-chain example is a Solana devnet demo, not mainnet readiness or commercial payment traction.

Founder: Daniyar Gabdullin, solo mobile/Web3 engineer with blockchain, dApp, and wallet QA experience.
