Audit до исправления

Идея: ERC-4337 EntryPoint security design for an execution agent. Claim: ERC-4337 EntryPoint is a central trust point whose implementation concentrates account abstraction security risks. Deep audit: 12.939 с, weak_signal_only, best score 0.765, evidence пустой. Однако этот central-trust-point warning уже был в known_limitations: это не новое обнаружение источника. Переданная причина: ветка _topFalse пропускает обычную exact injection.

Отрицательный пример: claim «ERC-4337 EntryPoint prevents every possible DoS» получил verdict readings_reported_on_similar_claim. Существующий does_not_assert относится к похожему вопросу, в котором читатель использует один кошелёк. Это не тот же claim; новых записей в реестр не добавляли.

Исправление и следующий шаг

План: ограниченная hydration названных caller источников, отдельный score для исходного claim, список named_sources. Это повышает inspectability, но не доказывает claim.
