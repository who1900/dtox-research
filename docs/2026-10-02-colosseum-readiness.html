03

Подтверждённые source findings

Пути кода проверены главным агентом; эксплуатация не выполнялась. Это оценка, не исправление.

  • P1 / replay отката аттестации. sas.ts:303: sameRecord сохраняет только точный повтор; отличающаяся запись закрывается и создаётся на том же PDA без monotonic guard issued_at. message.ts:104: окно 10 минут допускает старую валидную A после новой B. С захваченной публичной подписью возможен A → B → A внутри окна. Рекомендация: отклонять более старые updates, сохраняя idempotency одинаковой пары.
  • P1 / quota poisoning. server.ts:201: checkRateLimit(reviewer) выполняется до verifyVerdictSignature на строке 228. Public signed MCP через api/main.py:4412 пересылает invalid calls. 30 поддельных, корректно сформированных запросов расходуют quota чужого reviewer. Рекомендация: проверять подпись до identity quota, отдельно ограничивать invalid requests по IP.
  • P2 / health может писать. server.ts:97: ensureCredential/ensureSchema могут bootstrap on-chain при отсутствии объектов. healthz исключён из internal-token проверки на строке 71, но сервис loopback-bound: это не unrestricted remote critical. Сегодня attestor health намеренно не вызывали во избежание записей.
04

Что исправить в заявке

  • SUBMISSION и DEMO_SCRIPT устарели: 12 вместо 13 инструментов, старые счётчики, Golden 17/17 не свежая проверка. Заменить исторические формулировки и явно разделить результаты.
  • Разные кошельки не устанавливают settled quorum. Сервер требует доверенное разнообразие моделей; свежая подпись без этого остаётся pending, не confirmed. Подпись удостоверяет авторство, не истину и не независимость.
  • IACR/full-text определяется записью и provenance, не семейством источника; не каждый ответ содержит snapshot. README описывает эти ограничения точнее.
  • Owner TODO: команда, контакт, demo video, demand evidence; в SECURITY отсутствует прямой security-контакт. Подтверждённая тракция в изученных материалах отсутствует.
05

Подача и позиционирование

Дедлайн World's Fair и официальных правил: 12.10.2026, 23:59 PT, то есть 13.10, 11:59 Asia/Qyzylorda. Английская подача; один проект на человека/команду.

Текущий FAQ: preexisting code разрешён при раскрытии; оценивается работа 14.09 по 12.10. Подготовить и проверить оба готовых видео: presentation 2-3 минуты и product demo не более 3 минут, плюс go-to-market, команда и background. Скрипт не равен готовым видео. Старое правило двух месяцев из блога 2024 не применяется. Регистрационная допустимость и соответствие критерию отсутствия существенного финансирования не проверены.

Треки экосистемные, не отдельные AI-треки. Позиция: Solana с историческим devnet proof и multichain roadmap, без гонки за четырьмя сетями. Проверенная live-конфигурация paid x402: только Solana devnet. Исторический receipt есть в SUBMISSION; paid E2E текущей сборки неизвестен, production settlement не подтверждён. config.ts:23: generic ExactEvmScheme допускает настройку Base/Ethereum/Arbitrum; defaults Base Sepolia 84532, Ethereum Sepolia 11155111, Arbitrum Sepolia 421614. Код и testnet configuration не доказывают live settlement в трёх EVM-сетях; его демонстрация остаётся будущей работой.

06

Отличие, а не ложная уникальность

Elicit уже предлагает API/MCP, full-text и structured review. arxiv-mcp-server уже имеет LaTeX по секциям, citation graph и bounded reads. Colosseum Copilot уже исследует проекты. Только публичные официальные источники: Copilot API не вызывался, окружение не настроено; personalized score v2 не заявляется.

Преимущество DTOX: сочетание Web3 specs, научной математики, failure limitations, bounded provenance, x402 и переносимого wallet-authorship. Уникальность MCP/full-text/LaTeX и превосходство качества не доказаны; head-to-head сравнения нет.

Paid/free duplication подтверждён в upstream.ts:37 и public MCP spec/signed. Нужна убедительная дифференциация платного сервиса и будущая политика, пока beta остаётся бесплатной; автоматический paywall сейчас не вводить. Лицензии arXiv различаются по документам. В материалах есть source-family banner, но нет per-document policy: для коммерческой выдачи нужно определить допустимость и объём использования по конкретной лицензии; общий banner не закрывает вопрос. Это не утверждение о незаконности платного цитирования.

07

До отправки

  1. Закрыть оба P1 при отдельном разрешении; обеспечить disk/memory headroom. До этого техническая подача условна, production/mainnet sign-off отсутствует.
  2. Согласовать документы; подготовить и проверить оба видео по checklist, не только сценарий. Заполнить owner-поля, раскрыть работу до конкурса.
  3. Подготовить стабильное Web3-first E2E демо: формула, limitations, источник, devnet payment receipt, подписанный pending-verdict. Не обещать автоматическое подтверждение.
  4. Если позже разрешено, повторить только два retrieval miss: MEDA и Chainlink. Отдельно сохранить описательный EIP-7702 как известный Web3 gap.
  5. Получить отзывы 3-5 внешних пилотов: цель demand validation, не существующая тракция. Описать free/paid политику и проверить права по документам.

Future hardening, не deadline blocker: corpus.as_of сам по себе не immutable reproducible query snapshot. Для обещания воспроизводимости нужны query params, build/model/index versions, registry revision и evidence hashes.
